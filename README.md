# Robert Tworek

AI agents and the .NET systems around them. Wrocław, Poland.

I'm finishing a BEng in Technical Computer Science (medical information systems) at Wrocław University of Science and Technology, graduating February 2027. I spent 160 hours at KODA.AI on a production chatbot and voicebot platform, testing bots against real client scenarios and designing an R&D analyzer that finds where a voicebot fails customers. My own projects cover the backend side: C# and ASP.NET Core, PostgreSQL, Docker, and tests that run in CI.

## Selected work

- [order-flow-management-system](https://github.com/tworekrobert/order-flow-management-system): orders, inventory, payments and warehouse flow with role-based access, controlled order states and an outbox worker. ASP.NET Core 8, EF Core, PostgreSQL, Docker. 45 automated tests in GitHub Actions.
- [helpdesk-management-system](https://github.com/tworekrobert/helpdesk-management-system): internal IT helpdesk with ticket queues, SLA tracking, audit history and asset inventory. ASP.NET Core API with JWT, React, TypeScript, PostgreSQL. Unit, integration and Playwright end-to-end tests.
- [vaccination-programme-planner](https://github.com/tworekrobert/vaccination-programme-planner): vaccination schedules, reminders and coverage reports for a primary care clinic. ASP.NET Core 10, Angular, PostgreSQL, HL7 FHIR R4.
- [pharmacy-management-system](https://github.com/tworekrobert/pharmacy-management-system): desktop app for prescriptions, sales, deliveries and inventory, built in a team. My part: the Avalonia UI and the PostgreSQL layer.
- [tsp-algorithms-benchmark](https://github.com/tworekrobert/tsp-algorithms-benchmark): exact algorithms, heuristics and metaheuristics for TSP and ATSP compared in Python and C++.
