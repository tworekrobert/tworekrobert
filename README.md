# Hi, I'm Robert 👋

**Bots and LLMs.** [bot-message-analyzer](https://github.com/tworekrobert/bot-message-analyzer) reads chatbot and voicebot conversation logs, uses the Gemini API to judge every customer turn and ranks the topics the bot keeps failing on.

**.NET backends.** [OrderFlow](https://github.com/tworekrobert/order-flow-management-system) (orders, stock and payments with an outbox worker) and [Helpdesk](https://github.com/tworekrobert/helpdesk-management-system) (tickets, SLA and assets with a React console). ASP.NET Core, PostgreSQL, EF Core, Docker, tested with xUnit, Testcontainers and Playwright.

**Medical IT.** [VaxPlan](https://github.com/tworekrobert/vaccination-programme-planner), a vaccination schedule planner for a primary care clinic that exports patient data as HL7 FHIR R4.
