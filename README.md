## About

I am a **Technical Computer Science student at Wroclaw University of Science and Technology**, specializing in **IT systems in medicine**.

My repositories are focused on practical, runnable projects: desktop and web applications, relational databases, technical documentation, tests, setup instructions and portfolio-ready project structure. I try to build projects that show not only code, but also data models, user workflows, validation, reporting and clear documentation.

## Featured projects

| Project | What it shows | Stack |
| --- | --- | --- |
| [pharmacy-management-system](https://github.com/tworekrobert/pharmacy-management-system) | Desktop pharmacy system with customers, medicines, prescriptions, sales, inventory, reports, roles, audit logs, backup/restore and PostgreSQL-backed workflows. | C#, .NET, Avalonia UI, PostgreSQL, ODBC |
| [helpdesk-management-system](https://github.com/tworekrobert/helpdesk-management-system) | Full-stack internal IT support system with tickets, roles, comments, SLA tracking, asset inventory, audit history, exports, tests and Docker-based setup. | ASP.NET Core, React, TypeScript, PostgreSQL, Docker |
| [tsp-algorithms-benchmark](https://github.com/tworekrobert/tsp-algorithms-benchmark) | Four-stage benchmark of exact algorithms, heuristics and metaheuristics for TSP/ATSP, with reproducible configs, CSV results, plots and documentation. | C++17/20, TSPLIB, CSV, Makefile |

## Portfolio website

[bilingual-portfolio-website](https://github.com/tworekrobert/bilingual-portfolio-website) is my personal portfolio built with **Next.js, React, TypeScript and Tailwind CSS**. It presents selected project case studies, a GitHub repository index, CV download and contact section in Polish and English.
